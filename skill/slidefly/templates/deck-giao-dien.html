Sáu việc trợ lý làm tốt

  • Tóm tắt

    Rút ý chính từ file dài

  • Viết lại

    Đổi giọng văn cho hợp người đọc

  • Dịch

    Giữ đúng thuật ngữ của nhóm

  • So sánh

    Chỉ ra chỗ khác giữa hai bản

  • Lên dàn ý

    Xếp ý trước khi viết

  • Soát lỗi

    Chính tả, câu cú, số thứ tự

Hỏi rõ việc thì nhận đúng thứ cần

  • Nêu việc: tóm tắt, viết lại hay so sánh.
  • Nêu khuôn: mấy ý, mỗi ý dài bao nhiêu.
  • Nêu giới hạn: chỉ dùng tài liệu đã đưa.
Tóm tắt báo cáo tuần thành 3 ý, mỗi ý một câu. Chỉ dùng số có trong file.

Tiến độ: hai đầu việc xong, một đầu việc trễ hẹn.

Vướng mắc: chờ bên mua hàng duyệt báo giá.

Tuần tới: chốt báo giá trước thứ Tư.

Cài công cụ trong ba lệnh

git clone https://github.com/andyluu98/slidefly.git

Cloning into 'slidefly'...

cp -r slidefly/skill/slidefly ~/.claude/skills/
pip install -r slidefly/requirements.txt

Đã cài xong thư viện cho script kiểm tra.

  • Lệnh 1 tải bộ skill về máy.
  • Lệnh 2 chép vào thư mục skill.
  • Lệnh 3 cài thư viện kiểm tra.

Kết quả mở ngay trên trình duyệt

  • Một file: gửi qua chat là người nhận mở được.
  • Không cài gì: Chrome hoặc Edge là đủ.
  • Sửa nhanh: đổi chữ rồi mở lại.

Hỏi nhanh ngay trong cuộc họp

  • Câu ngắn: một việc mỗi lần hỏi.
  • Kiểm lại: đối chiếu với file gốc trước khi dùng.
  • Ghi nguồn: số liệu nào cũng truy được.
